## Canvass Lead Finder 1.0

**Discover. Validate. Analyse. Convert.**

### Download and run (Windows)

1. Download **Canvass-Windows.zip** below and unzip it.
2. Double-click **Start Canvass.bat**. Nothing else needs to be installed; Node.js is included.
3. If Windows shows "Windows protected your PC", click **More info → Run anyway**. The package isn't code-signed.
4. Open **Settings**, add your Google Places API key and save.

The included **Canvass User Manual.pdf** and **READ ME FIRST.txt** explain the rest.

### What's in 1.0

- **Google Auto Lead Finder:** pick country, city, area, industry and category, then discover and validate businesses through the Google Places API.
- **Bulk Upload Lead Finder:** Excel, CSV, website URLs, company names or Google Maps links, checked by the same engine.
- **Verification:** active-business checks, company and website age (documented dates, RDAP domain records, Internet Archive history), industry, location and size.
- **Audits:** Google Business Profile, customer reviews, and the website (availability, HTTPS, mobile, SEO, enquiry paths, WhatsApp, local SEO, AEO, PageSpeed).
- **Results:** Qualified, Unverified, Rejected or No Opportunity, plus a configurable 100-point lead score.
- **Pitches:** Canvass service recommendations and personalised pitches (email, WhatsApp, call script, proposal, free-audit offer).
- **Sales pipeline:** stages, assignees, follow-ups, notes, contact log and do-not-contact.
- **Free-tier protection:** monthly and daily limits on Google Places requests.
- **Data:** Excel and CSV export, automatic daily backups, restore, search history and API usage tracking.
- **Phones and tablets:** network mode with a PIN for devices on the same Wi-Fi.

### Not included yet

- Automatic sending of emails or WhatsApp messages (pitches are copied and sent by you).
- Team logins and cloud hosting.
